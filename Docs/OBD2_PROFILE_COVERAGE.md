# Реестр профилей: статус покрытия и источники

Рабочий документ команды. Правило: **профиль без проверки на живой машине — «кандидат»**, в продакшен-подборку идут только проверенные. Проверка занимает минуты: экран OBD Test → выбрать авто → Connect → Live → сводка в логе покажет `<профиль>: N` (N > 0 = профиль отдаёт данные).

## Toyota TNGA: разметка блока 2101 (живая калибровка, Camry 2019, 08.07.2026)

Ответ `21 01` → `61 01` + 27 байт. Смещения от начала данных (после эха `6101`).
Метод: три дампа в разных состояниях сверены с одновременными показаниями стандартных PID.

| Смещение | Значение | Формула | Сверено |
|---|---|---|---|
| 00 | Расчётная нагрузка | A×100/255 % | ✅ = std 0104 |
| 05, 06 | Температура впуска (2 сенсора?) | A−40 °C | ✅ = std 010F, падает при движении |
| 08 | Температура ОЖ | A−40 °C | ✅ = std 0105 |
| 09–0A | Обороты | AB/4 rpm | ✅ = std 010C |
| 0B | Скорость (кандидат) | A км/ч | ⏳ все дампы стояли (0) — проверить в движении |
| 0F | Дроссель | A×100/255 % | ✅ = std 0111 |
| 11 | Педаль газа D | A×100/255 % | ✅ = std 0149 |
| 12 | Педаль газа E | A×100/255 % | ✅ = std 014A |
| 13 | Актуатор дросселя | A×100/255 % | ✅ = std 014C |
| 18 | Напряжение (кандидат) | A/16 В | ⏳ похоже, не подтверждено |

`21 82` → `61 82` + 2 байта: **одна** температура `(AB/256) − 40 °C` (не две по A−40!). Датчик независим от ОЖ (после поездки 91° при ОЖ 87°) — масло ДВС или АКПП, различить по длинной поездке. `21 03` — топливный блок (тримы, дублирует std). `21 C4` — константы. `21 02` → NRC 12.

## Процесс добавления профиля

1. Найти в источнике: адрес ECU (запрос/ответ), команду (`22`+DID или `21`+block), формулу, единицы.
2. Создать/дополнить `Classes/OBD/Profile/Resources/<группа>.json` (формат — `Docs/OBD2_PROFILE_FORMAT.md`).
3. Зарегистрировать файл в Xcode-проекте (Resources build phase).
4. Проверить на живой машине через экран OBD Test (сводка в логе после Live ■).
5. Обновить таблицу статусов выше: 🟡 → ✅ (или удалить параметр, если NRC).

Неподошедший параметр не ломает ничего: ECU отвечает «не знаю» (`7F xx 31`), движок исключает его из опроса автоматически.
